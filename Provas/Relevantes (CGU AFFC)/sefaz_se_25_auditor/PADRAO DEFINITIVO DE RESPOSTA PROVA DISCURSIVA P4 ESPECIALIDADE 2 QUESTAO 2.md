PADRÃO DE RESPOSTA DEFINITIVO
O processamento analítico online (OLAP) é uma ferramenta usada para analisar dados de negócios de diferentes
pontos de vista, combinando e agrupando esses dados em categorias para fornecer insights acionáveis para o planejamento
estratégico.
Um sistema OLAP multidimensional apresenta os seguintes elementos, dos quais o(a) candidato(a) deverá citar pelo
menos dois: data warehouse, ferramentas de ETL, servidor OLAP, banco de dados OLAP, cubos OLAP e ferramentas
analíticas OLAP.
A modelagem de dados no OLAP armazena os dados multidimensionais em dois tipos de esquema: estrela e floco de
neve.
Extração, transformação e carregamento (ETL) correspondem ao processo de combinação de dados de várias fontes
em um grande repositório central, chamado de data warehouse. O processo de ETL usa um conjunto de regras de negócios
para limpar e organizar dados brutos e prepará-los para armazenamento, data analytics e machine learning (ML).
O processo de ETL funciona em três etapas: (i) extração dos dados relevantes do banco de dados de origem;
(ii) transformação dos dados para que sejam mais adequados a análises; (iii) carregamento dos dados no banco de dados de
destino.
A etapa intermediária do ETL é a etapa de transformação de dados, que pode envolver as seguintes técnicas de
alterações de dados, das quais o candidato deverá citar pelo menos duas: limpeza de dados, eliminação de duplicação de dados,
revisão de formato de dados, derivação, junção, separação, resumo e encriptação.
